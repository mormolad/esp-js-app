Ручной импульс

Кнопка — один щелчок реле (0.8 с).
Опасные пины
GPIO 15, 0, 2, 1, 3 — кандидаты для «невидимого» реле
GPIO 15 — безопасен: при загрузке как раз нужен LOW. Частый пин реле.
GPIO 0, 2 — стрэппинг загрузки: покой держится HIGH, иначе модуль может не стартовать. Если 4-е реле окажется здесь — лучше перекинуть его на свободный 4/5/13/16.
GPIO 1, 3 — UART: во время импульса консоль мусорит, для прошивки по USB реле с этих пинов отключите.
